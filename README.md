# Personal Portfolio Website

## 📌 Project Overview

The Personal Portfolio Website is a responsive web application developed using **HTML, CSS, and JavaScript**. The website serves as an online portfolio to showcase personal information, technical skills, projects, achievements, and contact details.

The project demonstrates the use of front-end web development technologies and provides a clean, interactive, and user-friendly interface.

---

## 🚀 Features

* Responsive design for desktop and mobile devices
* Dark mode toggle using Local Storage
* Dynamic Skills Section using JavaScript
* Dynamic Projects Section using JavaScript
* Contact Form Validation
* Smooth Scrolling Navigation
* Mobile Navigation Menu
* Scroll Animation Effects
* Download Resume Feature
* Social Media Links Integration

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Git & GitHub

## 📖 Working of the Project

### 1. Home Section

Displays profile image, introduction, resume button, and social media links.

### 2. About Section

Provides a brief introduction and career objectives.

### 3. Skills Section

Skills are stored in a JavaScript array and displayed dynamically using DOM manipulation.

### 4. Projects Section

Project cards are generated dynamically from JavaScript objects.

### 5. Achievements Section

Displays competitions, internships, and achievements.

### 6. Contact Section

Implements form validation using JavaScript.

### 7. Dark Mode

Uses Local Storage to save the user's theme preference.
